# TaskFire

个人 macOS 每日工作台。原生 SwiftUI 界面，支持飞书任务、自建任务、每日心得和按需知识沉淀。

## 运行

双击 `dist/TaskFire.app`，或使用 Codex Run 按钮。重新构建并启动：

```sh
./script/build_and_run.sh
```

仅构建：`./script/build_and_run.sh --build-only`。启动与进程检查：`./script/build_and_run.sh --verify`。

系统要求：macOS 14+；本地开发需 Swift 工具链与匹配的 macOS SDK。仓库提供 Package.swift，可使用正常的 SwiftPM/Xcode 工具链打开。初次构建时 Command Line Tools 中的 SwiftPM 动态库不匹配，因此 Run 脚本使用 swiftc 直接构建同一组源码，并显式选择已验证的 26.5 SDK；不会修改系统 xcode-select。安装完成的 Xcode 27.1 已通过标准 `swift test`，也可直接打开 Package.swift。

可通过 `TASKFIRE_SWIFTC` 和 `TASKFIRE_SDK` 指定另一组匹配的编译器/SDK。发行前仍需正式签名与公证；当前 .app 是本机临时签名的开发版本。

## 功能

- 今日：个人重点、两类任务、来源筛选、完成状态、心得速记。
- 计划：查看任意日期、明日安排、此前未完成和未排期任务；右键可快速安排。
- 任务：统一搜索、来源筛选；点击任务通过右侧详情调整安排。
- 项目：新建项目、按项目查看两类任务和完成情况；任务表单可以选择已有项目或新建项目，未分类任务保留单独入口。
- 记录：按日自动保存心得；按主题建立知识草稿，可关联任务与多日心得。
- 大盘：根据实际任务生成完成趋势、逾期与阻塞统计。
- 设置：lark-cli 路径、文档保存位置 token、数据路径及备份导出。

应用采用单主窗口，避免同一份记录被多个编辑器覆盖。没有内置示例业务数据。

## 飞书

安装并在终端配置 lark-cli，完成用户身份授权。设置中可指定 CLI 绝对路径，默认 `/opt/homebrew/bin/lark-cli`。

点击同步获取分配给我的任务，GUID 合并不会重复创建，不改变本机排期、重点和备注。任务标题及截止日期由飞书维护；在工作台完成或重新打开飞书任务时，先等待远端成功再更新本机。

自建任务仅本地保存，不自动创建飞书任务。计划日期与截止日期独立。

知识文档正文支持 Markdown，由用户手动点击发布。新草稿通过 `docs +create` 创建；已关联文档通过 `docs +update --command append` 将当前版本追加到文末，不覆盖飞书已有内容。目标可修改或解除关联；同一正文成功发布后不会重复提交。追加不是整篇同步编辑。网络超时或部分写入后，应先在飞书检查结果，避免重复提交。

应用不会自动登录、扩大授权、自动重试写操作，或代替用户确认 CLI 的高风险操作。权限/钥匙串错误会显示在界面中。

## 数据

正式数据：`~/Library/Application Support/TaskFire/workspace.json`。JSON 原子保存，包含任务、日期心得、知识草稿、关联的飞书标识与设置；不保存 CLI 账户密钥。文件损坏时暂停写入并显示路径，不以空数据覆盖原文件。设置中支持导出备份。

隔离测试：启动时传 `--data-file /绝对路径/workspace.json`。QA 数据位于 `.build/qa`，不会进入正式记录。

## 验证

```sh
./script/test.sh
```

便携检查覆盖：排期与期限独立、GUID 合并与去重、两类任务同名独立、CLI 实际 items 格式与完成状态、错误/分页拒绝、空列表、持久化和损坏保护、完成时间保留、旧编辑器不回退远端状态、部分发布不标记成功。标准 `swift test` 已通过 10 项 XCTest，便携入口已通过 10 项检查。

原生界面已验证新建任务、设置重点、完成进度、心得保存、通过 lark-cli 实际获取任务。没有对真实飞书任务执行完成回写，也没有为了测试创建或修改真实飞书文档。

设计稿保留在 `design/`；它是前期 HTML 交互预览，与原生应用的数据互不相通。

项目目录单独保存，空项目也会保留；原有任务的项目字段自动纳入项目列表。升级兼容不包含项目目录字段的旧数据。
