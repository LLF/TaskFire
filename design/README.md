# TaskFire macOS 页面设计稿

设计目标：个人每日工作台。飞书任务与自建任务统一排期；每日心得保存在本机，需要长期沉淀时才创建或更新飞书文档。

## 查看

打开 `index.html`，或在本目录运行 `rtk python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765。

本稿为 HTML 交互设计预览，尚未实现原生 macOS 应用或实际飞书接入。任务及统计均为示例数据；任务变更刷新后重置，心得及知识草稿使用浏览器本地存储。

## 页面

- 今日：重点任务、统一任务清单、来源筛选、心得速记、明日计划和最近沉淀。
- 计划：明日安排与未排期任务，任务详情可调整个人计划日期。
- 任务库：来源筛选、项目筛选、任务搜索与详情。
- 记录：每日心得与按主题组织的知识沉淀。
- 大盘：完成趋势与待关注事项，指标为示例。

## 原生实现对应

- 主窗口采用 WindowGroup，NavigationSplitView 提供侧边栏与内容区。
- 工具栏承载搜索、新建、刷新；任务详情使用 inspector。
- 设置采用独立 Settings 场景。
- 使用系统字体、语义颜色及浅色/深色外观，橙色作为强调色。
- SwiftUI 负责界面；本机服务通过受控参数调用 lark-cli，访问飞书任务与文档。账户信息不进入前端。
- 飞书任务以 GUID 关联，自建任务保留独立 ID。个人排期独立于截止日期。
- 心得按日期保存，知识文档按主题组织，支持关联多条任务与多日心得。

图标源于 Lucide（ISC 许可）。窗口控制圆点为设计装饰。
